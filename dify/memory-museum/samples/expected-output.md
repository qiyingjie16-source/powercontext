# 展示输出参考

模型输出可以有多种表达。以下是第二场样例应呈现的结构和关系。

```markdown
### 🏛️ 联动新展：《绿色书签申请延期》

**年代**：冰箱纪·第二次结霜

> 灰灯馆长在旧展柜里认出了那片香菜。它没有失踪，它只是把第一次展览延期了。

**馆藏部件**
- 一片拒绝腐烂的香菜
- 一台假装不知情的冰箱
- 一份迟到的结局申请书

**给你的回声**
上一场里，它是《一片香菜的最后晚餐》。这一场，它终于承认自己其实是一名长期驻馆艺术家。

---
🔐 灰灯馆长已把这件小事封存进 PowerContext。
馆藏编号：`artifact-...`
```

关键不是固定文案，而是：

1. 第二场明确认出了第一场。
2. 旧记忆通过 PowerContext 恢复，而不是硬编码在提示词中。
3. 第二场又被写成新的可检索记忆。
